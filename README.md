# 🖼️ Image Encryption Tool – Pixel Manipulation

A Python-based tool to **encrypt and decrypt images** using simple **pixel manipulation techniques**.  
This project supports two main operations: **swapping pixel values** and **shifting pixel values** with a mathematical transformation, making the image unreadable without decryption.

---

## 📖 How It Works
- The program reads an image and accesses its **pixel data**.  
- Users can choose between two encryption operations:
  1. **Swap Pixels:** Randomly or systematically swaps pixel positions across the image.  
  2. **Shift Pixels:** Applies a **mathematical operation** (e.g., adding a shift value) to pixel RGB values.  
- The encrypted image appears **scrambled**.  
- Applying the reverse operation restores the original image.

---

## 🚀 Features
- Encrypt and decrypt images with **pixel-level manipulation**.  
- Supports **Swap** and **Shift** operations.  
- Works with common image formats like PNG, JPG, JPEG.  
- CLI-based tool — lightweight and easy to run.  
- Uses only Python with **Pillow** library.
